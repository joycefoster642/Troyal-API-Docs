# Troyal-API-Docs
Documentation for Troyal, a fictional B2B SaaS API for tracking music and film royalties, ownership splits and licences. A technical writing portfolio project.

# What Troyal Does
Troyal is a cloud platform that brings transparency to the relationship between artists and labels. Today, artists often can't see who owns a work, what they're owed, or whether payments match their contract. This leads to late payments, errors and disputes.

Troyal gives labels, entertainment law firms and management companies one place to:

- **Track royalties** for every work, artist and territory
- **Manage ownership splits** so everyone can see who owns what share
- **Track streams and usage** from reporting data
- **Generate statements of account** for each payee
- **Maintain artist and label profiles,** including statements of ownership

# About this project

I built Troyal to practise documenting a real B2B SaaS product, from the first idea to the finished docs. I heard so much about royalty problems in the music industry that I wanted to build something around it, even if it's only on paper.

I'm using Markdown, GitHub and Jira, and I'm sharing each step as I go on LinkedIn, Dev.to and Hashnode.
